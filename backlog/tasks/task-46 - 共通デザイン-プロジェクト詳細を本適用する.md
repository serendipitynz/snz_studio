## 変えたもの
- 削除の破壊前確認 (AC#1): 文書・チャット・記憶の行内の吹き出しをやめ、確認ダイアログ (モーダル) にした。見出し「ドキュメントを削除」など、本文「『名』を削除します。元に戻せません。」、実行のボタン「削除する」(破壊的操作)、既定の焦点は「キャンセル」。プロジェクトの削除も同じ形にし、ボタンを破壊的操作の変種にした (前は通常の変種に色を上書きしていた)。確認ダイアログ (`useConfirm`) に呼び出しごとの見出しとボタンの語を渡せるようにした。渡さない呼び出しは今までどおり「キャンセル / OK」で、残りの呼び出しの語は TASK-48 が受け持つ。
  - 削除で行が消えると焦点が画面の先頭へ落ちるので、同じ一覧の隣の行の削除ボタンへ移し、最後の行なら区画の近くの受け手 (文書 → 画像追加、チャット → メモリを編集、記憶 → 整理) へ移す (doc-9 §5.1)。行が DOM から消えてから移す。WebKit では、次のフレームの時点でまだ行が残っていたため。
  - 再読み込みのたびにページ全体を「読み込み中」のカードへ差し替えていたのをやめた。削除や取り込みの後に、開いているダイアログが閉じ、焦点が先頭へ落ちていた。
- ドロップゾーン (AC#2): `components/FileDropZone` を作り、プロジェクト詳細と画像文書のダイアログで使う。ファイルが上にある間は、輪郭を実線の accent、面を accent-soft にし、語を「ここで離すと取り込みます」に差し替える。ドラッグ中に種類が分かって受け付けないときは、輪郭を danger にし、語を「この種類のファイルは取り込めません」にする。落とした・選んだファイルのうち受け付けないものは取り込まず、ゾーンの誤り域で名と受け付ける種類を述べる (図形付き、role="alert")。合うものだけを渡す (前は1つでも合わないと、残りも止めていた)。操作域に「ファイルを選ぶ」ボタンを置き、見出しの + はこれに移した。取り込み中は、量が分かる進捗 (`components/Progress`、N 件中 i 件、doc-8 §6.7.1) を、ゾーンの寸法を保ったまま出す。落とす・選ぶは受け付けず、理由を述べる。上書きになる取り込みの前に破壊前確認 (「ドキュメントを上書き」「上書きする」) を通す。ゾーンの外に落ちたファイルは、`AppShell` で既定の動作を止める (チャット画面にも効く)。`ThemeTokens` に `onAccentSoft` を足した。標準 と Solarized は共通の役割から写し、追加の5配色系統は本文色から取る。
- 破棄前確認 (AC#3): 題名・システムプロンプトのモーダルで、下書きが保存値と違うまま閉じる (閉じるボタン・Escape) と、「変更を破棄しますか？」(「破棄する / 編集を続ける」、既定は留まる側) を出す。破棄したら下書きを保存値に戻す。保存中は閉じない (閉じるボタンは無効で理由を持ち、Escape も効かない)。同じ確認を、入力を捨てる画像文書の追加ダイアログと、文書のダイアログ (説明文の編集中・カテゴリの未保存) にも付けた。記憶のモーダルは、書きかけを閉じても保持するので、確認を持たない (doc-9 §5.7 の「捨てる部品だけが確認を持つ」)。
- 失敗の置き場所 (AC#4): ページ先頭の1つの error を、領域ごとに分けた。新しいチャット・文書区画・危険な操作・チャット区画・記憶のモーダル (追加フォームと一覧)・整理の提案・各モーダルの中に `FailureNotice` (失敗の段) を出す。モーダルの中の操作の失敗は、前は背後のページの先頭に出ていたので、モーダルの中に出すようにした。区画の見出しを代用していたバッジ (システムプロンプト・メモリ・チャット・危険な操作・記憶の種類・抽出テキスト) を見出しの語 (h2 / h3) に戻した。

操作 (Chromium と WebKit の両方で全 93 項目が通った):
- 削除: Enter で開いた確認の見出し・名・「元に戻せません」・既定の焦点がキャンセル。Enter と Escape は取り消し、要求は出ない。取り消した後の焦点は削除ボタン。実行すると要求は1回で、焦点は次の行の削除ボタン、最後の行ならその区画の受け手。記憶のモーダルでは、Escape は確認だけを閉じ、焦点はモーダルに残る。削除の失敗の告知は文書区画に出て、行は残る。

- 破棄前確認: 題名が保存値のままなら、Escape で聞かずに閉じる。変えると Escape で「変更を破棄しますか？」が出て、既定の焦点は「編集を続ける」。Enter で留まり、下書きは残る。破棄すると閉じ、開き直すと保存値から始まる。システムプロンプト・画像文書の追加・文書のダイアログ (カテゴリ・説明文の編集) も同じ。保存中は、閉じるボタンが無効で理由「保存が終わると閉じられます」を持ち、Escape でも閉じない。保存が終わると聞かずに閉じる。
