## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-55 の着手時のオーナーの要望 (2026-09-27)。Claude Code や LM Studio のように、会話で使えるトークン数に対してどれだけ消費しているかを、入力欄の箱の小さな進捗 (グラフ) で出したい。TASK-55 は「n ターン目」の状態バッジと、発言の総数が 1 ターンの読む上限 (TurnHistoryLimit = 30) を超えたときの語だけを入れた。

今のコードはこれを出す材料を持たない:
- チャット補完のストリームは使用量 (prompt / completion tokens) を受け取っていない (OpenAI 互換の stream_options.include_usage を送っていない)。
- モデルのコンテキスト長を取得していない。LM Studio のネイティブ API はモデルごとの最大コンテキスト長を返すが、OpenAI 互換の /models は返さない。
- 多人数会話では参加者ごとにモデルと接続先が違いうるので、「会話で使えるトークン数」が参加者ごとに違う。何を分母にするか (次の話者のモデル・直前のターンの話者のモデルなど) を決める必要がある。

着手時に決めること: 分母 (どのモデルのコンテキスト長か)、分子 (直前のターンのプロンプトのトークン数か、次のターンの見積もりか)、コンテキスト長を返さない接続先での出し方、単独チャットにも出すか。
