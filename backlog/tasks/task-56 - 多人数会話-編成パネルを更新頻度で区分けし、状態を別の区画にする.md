## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-47 (#47) の後のオーナーの実窓の確認 (2026-09-26) で出た、複数エージェントチャットの編成パネル (`ParticipantPanel`) の構成についての指摘。オーナーの注記: 「会話の設定・参加者の編成の内容粒度を精査したい」。

オーナーの注記による、今の欄の更新頻度:
- 会話の設定
  - ターン進行ルール・場面設定: 更新頻度は低め。
  - 共通の状態: 会話の状況に応じて変わる。
- 参加者ごと
  - 表示名・役割プロンプト・プロジェクト資料を渡す: 更新頻度は低め。
  - 状態: 会話の状況に応じて変わる。
  - 接続先・接続確認・モデル: 基本的に最初だけ。

オーナーの素案 (2026-09-26、画面の注記から):
- パネルの見出しを「編成」から「インスペクタ」に変える。単独チャットのコンテキストインスペクタと呼び方を揃えると読んだ。見出し帯のトリガーの名前と、読み上げの語も合わせる。
- 「状態」の区画 (状態パネル) を切り出して、パネルに足す。素案の図では、既存の区画の前 (上) に置いている。
  - 中身: 「共通の状態」の欄と保存。続けて、参加者ごとにその表示名を見出しにし、その参加者の「状態」の欄と保存を置く。並びは編成の順。
- 「会話の設定」の区画から「共通の状態」を、参加者のカードから「状態」を、それぞれ状態の区画へ移す。会話の設定と参加者のカードには、更新頻度の低い欄と接続の欄が残る。

着手時に確かめること:
- 状態の区画の置き場所。素案の図では、インスペクタの中の先頭の区画に見える。インスペクタの外の別の区画にするかどうかを確かめる。
- 「基本的に最初だけ」の接続の欄 (接続先・接続確認・モデル) を、畳んだ区画 (doc-9 §6.3) にするか。素案は手を入れていないので、変えないのが既定。
- 除籍した参加者の状態は、状態の区画に出さない。今も編成にいる参加者だけに状態の欄がある。

保つもの:
- 状態のシートは、ターンの実行中・自動進行中も編集と保存ができる (design §4.7)。
- 書きかけは、区画を消しても残る (TASK-47)。状態の欄を参加者のカードから移しても、保存値からの書きかけの初期化 (保存値を key にした作り直し) の振る舞いを変えない。

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. CollapsibleSection を拡張: 制御された collapsed (collapsed + onToggle) と、見出し域の操作 (actions) を受けられるようにする。本体は hidden のまま (書きかけを保つ)。
2. ParticipantPanel を再構成: 見出しを「インスペクタ」に。区画は プリセット (開始前のみ・畳み既定) → 状態 (開始前は畳み・開始後は展開既定) → 会話の設定 (開始前は展開・開始後は畳み既定) → 編成 (見出し + 参加者ごとの折畳みカード) → 追加フォーム → 除籍済み。会話開始 (発言 0→1) の遷移で、状態を開き、会話の設定と参加者カードを畳む。
3. 状態の区画: 共通の状態の欄 + 保存、続けて編成順に参加者の表示名を見出しにした状態の欄 + 保存。参加者カードから状態の欄を外す。ターン中も編集・保存可 (StateSheetField は lockedReason を取らないまま)。
4. 参加者カード: 見出し域 = 折畳みトリガー (図形 + 表示名) + 上下移動・退席 (畳んでも操作可)。本体 = 表示名・役割プロンプト・資料 + 保存、区切り線、接続先・確認・モデル + 保存 (dirty 判定を2グループに分ける)。追加直後の参加者のカードは展開する。
5. ページ側: 出し入れトリガーの名前・読み上げ・区画の aria-label を「インスペクタ」に。i18n (ja/en) に multiAgent.inspector・showInspector/hideInspector・participants.stateSection 等を足す。
6. docs/current-spec(.ja).md の多人数会話画面の説明を新構成に合わせる。
7. Playwright (Vite dev server) で変えた箇所の比を4配色で測り、キーボード到達を確かめ、pnpm check:client・build:client を通す。

## Implementation Notes

## オーナーの判断 (2026-09-26、着手時のメッセージから)
- 状態の区画はインスペクタの中の先頭。区画は折り畳みにし、既定は会話開始の前後で変える: プリセット=開始前のみ・畳み既定 / 状態=開始前は畳み・開始後は展開 / 会話の設定=開始前は展開・開始後は畳み / 参加者カード=個別折り畳みで同様。会話が始まった瞬間 (発言 0→1) に、状態を開き、会話の設定と参加者カードを畳む。
- 参加者カードは畳んだままでも並べ替え・退席ができる。接続の欄 (接続先・確認・モデル) はカードの中に残し、上に区切り線。
- 接続先の入力と「確認」ボタンは同一行、ボタンの図形は無し、語は「確認 / Check」。
- 会話の設定・状態の保存、「このプリセットを適用」は右寄せ。
- 状態の区画の参加者の欄は、見出しを立てず「**表示名**の状態」をラベルにし (表示名は太字)、字数カウンタはラベル行の右端。
- TASK-47 のフィードバック画像 (_sandbox/task-47-feedback) の素案どおり。

## 変えたもの
- 見出し (AC#1): パネルの見出し・出し入れトリガーの aria-label と title・区画の aria-label・読み上げの語を「インスペクタ」(en: Inspector) にした (multiAgent.inspector / showInspector / hideInspector)。participants.title は消した。進行役の注記とプリセットの注記の「編成パネル」もインスペクタに直した。
- 状態の区画 (AC#2): インスペクタの先頭 (プリセットの次) に「状態」を足した。共通の状態と、編成にいる参加者ごとの状態シート (編成順)。参加者カードから状態の欄を外した。除籍済みは出ない (編成だけを回す)。保存の失敗はこの区画の中の欄の直下に出す (状態専用の error 置き場を足した。カードが畳まれていても見える)。
- ターン中の編集 (AC#3): StateSheetField は今までどおり lockedReason を取らない。実行中のターンを固定した状態で、編集・保存が通り、ターン進行ルールの選択欄はロックされることを確かめた。
- 折り畳み (AC#4): CollapsibleSection に制御モード (collapsed + onToggle) と見出し域の操作 (actions) を足した。本体は hidden のままなので書きかけは畳んでも残る (TASK-47 の保持)。参加者カードは見出し=折り畳みトリガー (図形+表示名)、その右に上下移動・退席。開閉の選択は保存しない (既定は開始前後で決まる)。追加直後の参加者のカードは会話中でも開く (役割・接続が空のままのため)。
- 参加者カード: 表示名・役割プロンプト・資料+保存 / 区切り線 (Divider, line-divider) / 接続先+確認・モデル+保存 の2グループに分け、dirty 判定と保存を分離した。編成の見出しは区画カードの外に出し、カードの入れ子を1段浅くした。
- HintedField に labelContent (太字の名前を含む表示) と labelEnd (カウンタ) を足した。ラベルの語 (hint の名前・読み上げ) は文字列のまま。翻訳の {name} を番兵で分割して太字にする (participantStateOf)。
- docs/current-spec(.ja).md の多人数会話画面 (§11.6 / Multi-agent chat screen) とプリセット・編成の語を新構成に合わせた (AC#5)。
