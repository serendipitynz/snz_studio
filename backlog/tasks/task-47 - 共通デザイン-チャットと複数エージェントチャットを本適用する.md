## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. 処理中の図形 (AC#3): SpinnerIcon を icons.tsx の1つにまとめ、SMIL をやめて CSS の回転にする。周期は共通値 motion.spin (700ms)、prefers-reduced-motion では motion.spinReduced (2000ms)。止めない。
2. 区画の出し入れ (AC#1): チャットのインスペクタと複数エージェントチャットの参加者列のトリガーに aria-expanded・aria-controls を持たせ、出ている間は面 surface-selected・輪郭 selected にする。広い幅 (>1180px) は今の保存値に従う。1180px 以下では区画を自動で消し (保存値は書き換えない)、トリガーは残す。押すと 901〜1180px では3列目、900px 以下では本文の下に出し、出た位置を読み上げる。狭い幅で出したことは保存しない。消すとき焦点が区画の中にあればトリガーへ移す。参加者パネルは書きかけを持つので、消しても unmount しない。(オーナー判断 2026-09-26: その場に出す)
3. 会話 (AC#2): 描き分け (assistant のアクセントの枠と面、user の右寄せと別の面) は変えない (オーナー判断 2026-09-26: 配色で区別がつくので対応不要)。14 組 (7配色系統 × 明暗) で面と枠の比を測って記録する。生成中の発言が確定済みと同じ吹き出しで、複数エージェントでは発言者名とともに出ることを確かめる。
4. 参加者パネル (AC#4): details/summary の折り畳み区画 (プリセット・削除済み) を doc-9 §6.3 の折り畳み (見出しの中のボタン、aria-expanded、向きの変わる図形、焦点の枠) にする。区画の見出しのバッジ (設定・参加者の並び、インスペクタの3つ) を見出しの語に戻す。上下移動は §6.9 の状態を持たせる: 端と生成中は aria-disabled と理由、保存中は処理中で寸法を保ち押下を受けない、動かした後に焦点を同じボタンに保ち新しい位置を読み上げる、失敗はその参加者のカードに出す。(?) の補助表示を doc-8 §6.9 にする: 押して開く・hover でも開く・猶予付きで閉じる・本体にポインタを乗せられる・Escape で閉じてトリガーへ戻す・外側の押下で閉じる。押せる範囲は target-min (24px)。
5. 失敗の置き場所 (AC#5): ページ先頭の ErrorText をやめ、FailureNotice を対象の近くへ出す。チャット: 送信は入力欄、題名はそのモーダル、取り込みは文書のモーダル、レビューはレビューのモーダル、書き出しは見出し帯の下、コピーはその発言。複数エージェント: 読み込み・再読み込みは本文の先頭、ターン・介入・結論は入力欄、記憶の下書きの取得はその発言。参加者パネル: 設定・各参加者のカード・追加フォーム・プリセットの区画ごと。
6. 無効と処理中 (AC#6): disabled をやめ、ActionButton の disabledReason (焦点を受け理由を述べる) と busy (語と幅を保つ) にする。選択欄は aria-disabled と理由を持ち、開く・変える操作を受けない。
7. チャットのドロップゾーン (AC#9): 文書の追加モーダルを FileDropZone にし、受け付けない種類を述べ、進捗を出す。上書きの確認は今の確認を保ち、見出しと実行の語を project の形にそろえる。
8. check:client・build:client を通し、Vite の開発サーバー + Playwright (Chromium / WebKit、/api は route で固定) で4配色の比、14組の会話の比、キーボードの到達、配置 (1280・1000・800・600・360px) を測る。

## 変えたもの
- 区画の出し入れ (AC#1): `components/useSideRegion` を作り、チャットのインスペクタと複数エージェントチャットの編成パネルに使う。トリガーは aria-expanded・aria-controls を持ち、出ている間は面 surface-selected・輪郭 selected にし、図形 (panel-right-close / open) の向きも変わる。広い画面の選択は今までどおり localStorage のキー (`snz.chat.inspectorCollapsed` / `snz.multiAgent.rosterCollapsed`) に書く。1180px を跨ぐと区画は自動で消え、保存値は書き換えない。狭い画面で出したことは保存しない。消えるとき焦点が区画の中にあればトリガーへ移す (幅を跨いで消えるときも)。出した位置 (右の列 / 会話の下) を読み上げる。区画は読み順で会話の後ろにあるため。編成パネルは書きかけを持つので、消しても unmount しない (hidden)。`WorkspaceShell` の `$columns` を `$side` (列の有無) に変え、`InspectorPane` は出し入れする画面では `$toggled` で hidden に従う。トリガーを持たない画面 (プロジェクト詳細) は今までどおり 1180px 以下で消える (TASK-53)。`useMediaQuery` を `WorkspaceSidebar` から `components/useMediaQuery` へ移した。
- 処理中の図形 (AC#3): `SpinnerIcon` を `components/icons` の1つにまとめ (チャット・複数エージェント・プロジェクト一覧にあった3つの写しを消した)、SMIL をやめて CSS で回す。周期は共通値 motion.spin (700ms)、prefers-reduced-motion では motion.spinReduced (2000ms)。止めない。前は 0.8s で設定を見ていなかった。全画面に効く。
- 会話 (AC#2): assistant の吹き出しの補助の語 (時刻・応答の数値・モデル名) が Solarized Dark で 4.42 と 4.5:1 を割っていた (前は不透明度 0.78 も掛かっていた)。吹き出しの中の補助の語に、アクセントの淡い面に載る語の役割 (onAccentSoft) を当てた (CSS 変数 `--meta-ink`)。補助の語に掛けていた不透明度 (0.62〜0.78) と、発言ごとの操作ボタンの不透明度 (0.82) も外した。生成中の発言は今までどおり確定済みと同じ吹き出しで描く。複数エージェントでは生成中も発言者名を出す。
- 参加者パネル (AC#4):
  - 折り畳み区画: `<details>` をやめ、`components/CollapsibleSection` (見出し h3 の中のボタン、aria-expanded・aria-controls、向きの変わる図形、hover・押下の面、焦点の枠) にした。プリセットと除籍済みの参加者の2か所。回転は動かさずに切り替える (reduced motion)。
  - 区画の見出しをバッジで代用していた箇所 (会話の設定・編成、インスペクタのチャット要約・最新の参照・プロジェクトプロンプト、レビューの参照) を見出しの語 (h3) に戻した。
  - 上下移動 (doc-9 §6.9): 端では aria-disabled と理由 (編成の先頭 / 末尾にいます)。保存中は押したボタンが処理中 (寸法を保つ) になり、並び全体が aria-busy、2回目の押下は受けない。動かした後、焦点は動いたカードの同じボタンに残り、新しい位置を読み上げる (「ボブ」を 3 人中 1 番目へ移しました)。失敗はそのカードに出る。参加者を外した後の焦点は隣のカードの削除ボタン、最後なら追加フォームの表示名へ。
  - 補助表示 (doc-8 §6.9): `components/Hint` にした。押して開く・hover でも開く・hover で開いたものは離れて 300ms の猶予の後に閉じる・本体にポインタを乗せられる・hover の後の押下で留める・Escape で閉じてトリガーへ戻す・外側の押下で閉じる。押せる範囲は 24px。案内の語をトリガーの説明 (aria-describedby) にした。前は (?) が欄を包む label の最初の要素だったので、ラベルが入力欄ではなく (?) のボタンを指していた (共通の状態・接続先・モデルの欄が名前を持たなかった)。語を label for で欄に結び、(?) を label の外に置いた。
- 失敗の置き場所 (AC#5): ページ先頭の ErrorText をやめ、FailureNotice を対象の近くに出す。チャット: 送信は入力欄、書き出しは見出し帯の下、題名・取り込み・レビュー (とレビューのコピー) はそれぞれのモーダル、発言のコピーはその発言、読み込みは会話の先頭。複数エージェント: ターン・介入・結論は入力欄、記憶の下書きの取得とコピーはその発言、書き出しは見出し帯の下。参加者パネル: 会話の設定・各参加者のカード (保存・移動・外す・接続確認)・追加フォーム・プリセットの区画 (PresetPicker の読み込み失敗も)。送信の失敗の後の読み直しで、ページ全体を「読み込み中」に差し替えていたのをやめた (初回だけ差し替える)。
- 無効と処理中 (AC#6): 両画面・参加者パネル・モーダルで `disabled` をやめ、ActionButton の disabledReason (焦点を受け、理由を aria-describedby と title に持ち、押すと読み上げる) と busy (語と幅を保ち、図形域に処理中の図形) にした。語を差し替えていたボタン (送信中… / 保存中… / 確認中… / 追加中… / 適用中…) は語を保つ。幅を保つため、処理中になり得るボタンに図形を持たせた (送信・1 ターン進める・自動進行・発言・保存・参加者を追加・接続確認・適用)。選択欄は `components/GuardedSelect` (aria-disabled と理由、開く・変える操作を受けず理由を読み上げる) にした: ドキュメントの挿入 (ドキュメントが無い・取り込み中)・ターン進行ルール・進行役・プリセット (発言の生成中・自動進行中)。題名とメモリのモーダルは、保存中は閉じず、閉じるボタンが理由を持つ。主操作は、チャットは「送信」、複数エージェントは「1 ターン進める」の1つにした (自動進行・発言・パネルの保存は通常の変種)。
- チャットのドロップゾーン (AC#9): 文書の追加モーダルを FileDropZone (TASK-46) にした。上にある間の語と実線、受け付けない種類を名で述べて合うものだけ取り込む、件数の進捗。上書きの確認は今の確認を保ち、見出しと実行の語をプロジェクト詳細と同じ「ドキュメントを上書き」「上書きする」にした。語はプロジェクト詳細の語を使い、使わなくなった chat の語を消した。
- 確認ダイアログの語 (この画面の分): 参加者を外す (「参加者を外す」「外す」)、プリセットの適用 (「プリセットを適用」「置き換える」)。
- `docs/current-spec(.ja).md` のチャット画面と多人数会話画面に、区画の出し入れ・ドロップゾーン・失敗の置き場所を書いた。
- アイコンの path は lucide-static 1.47.0 から写した (npm の最小公開経過日数の設定で 1.48.0 を取れなかった)。`icons.tsx` の先頭に書いた。
