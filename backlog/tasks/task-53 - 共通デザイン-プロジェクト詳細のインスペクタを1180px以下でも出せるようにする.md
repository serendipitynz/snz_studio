## 確かめたこと

- 倍率 1。比は 1280×800、出し入れは 1280・1000・800×800。入力は Playwright が送る合成のキー・ポインタの事象 (物理キーボードではない)。
- 配色: 4配色 (標準 Light / 標準 Dark / Solarized Light / Solarized Dark)。表示言語 ja。測定日 2026-09-26。
- 画面は Vite の開発サーバーで出し、`/api/*` は Playwright の route が固定の JSON (プロジェクト1件・メモリ1件・チャット1件) を返した (リポジトリには足していない)。

比 (描かれた色から WCAG 2.x の式で計算。順に 標準 Light / 標準 Dark / Solarized Light / Solarized Dark):
- 出ている間の輪郭 (selected) 対 見出し帯 7.31 / 6.73 / 5.41 / 5.88、図形 対 その面 11.65 / 9.79 / 10.38 / 10.15、面 (surface-selected) 対 見出し帯 1.24 / 1.17 / 1.16 / 1.04。
- 消えている間の輪郭 対 見出し帯 4.05 / 3.83 / 4.13 / 3.26、図形 対 その面 14.42 / 11.44 / 12.05 / 10.61。
- 焦点の枠 (Tab で到達、:focus-visible) 対 見出し帯 7.31 / 6.73 / 5.41 / 5.88。
- 値はチャット画面のトリガー (TASK-47) と一致する (同じ部品・同じ見出し帯)。消えている間の輪郭の 3.26 (Solarized Dark) は doc-8 §6.2 の 3:1 を満たす。

AC#1: 4配色とも aria-expanded が出ている間 true・消えている間 false、図形が panel-right-close / open で変わる。1000px・800px でトリガーは見えて押せる (aria-expanded=false から始まる)。
AC#2 (1000px・800px の両方、キーボードだけ): トリガーで Enter → 区画が重なって出て、焦点は区画の閉じるボタンへ。Tab でシステムプロンプトを編集 → メモリを編集 → チャットのリンク → チャットを削除の順に届く (メモリの編集・削除はメモリを編集のモーダルの中)。システムプロンプトを編集で Enter → モーダルが開き、Escape で閉じると焦点は同じボタンへ戻り、区画は出たまま。チャットを削除で Enter → 名を述べる確認ダイアログが出て、Escape で取り消すと区画は出たまま焦点はチャットを削除へ戻る。区画の中から Escape → 区画が消え、焦点はトリガーへ。800px では区画の後ろへ Tab で進み、区画に隠れた見出し帯の編集ボタンに焦点が移ると区画が閉じる (hook の既存の振る舞い、WCAG 2.4.11)。
保存値: 1280px で消す → `snz.project.inspectorCollapsed` が "true"、再読み込み後も消えたまま。チャットのキー (`snz.chat.inspectorCollapsed`) は書かれない。1000px・800px で出し入れしても保存値は書かれない (null のまま)。出ている状態 ("false") で区画の中に焦点を置いたまま 1280 → 1000px にすると、区画が消えて焦点はトリガーへ移り、保存値は "false" のまま。1280px に戻すと区画は再び出る。
AC#4: `pnpm check:client`・`pnpm build:client` が通る (Go は変えていない)。
