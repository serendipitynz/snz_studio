## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-46 の Implementation Notes が「オーナーの判断を待つ」として残した件。オーナーの判断 (2026-09-26、TASK-47 の着手時): TASK-47 とは別のタスクにする。

プロジェクト詳細 (ProjectDetailPage) のインスペクタ (システムプロンプト・メモリ・チャット) は、1180px 以下で `InspectorPane` の `display: none` により消える。この画面には出し入れのトリガーが無いので、狭い幅ではシステムプロンプトの編集、メモリとチャットの編集・削除へ届かない。snz-design doc-9 §6.3.1 は「画面幅が狭い側へ変わって区画が自動で消える場合も、トリガーを残す」と定める。

TASK-47 がチャットと複数エージェントチャットに当てた出し入れの形 (トリガーの aria-expanded と見え方、1180px 以下で自動で消しても保存値は書き換えない、押すと 901〜1180px では3列目、900px 以下では本文の下に出す) を、この画面にも当てる。適用の結果は snz-design の「snz_studioの共通デザイン適用記録」に記録する。
