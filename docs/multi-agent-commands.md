# 多人数会話のスラッシュコマンド

多人数会話では、発言の最後の行に `/` で始まるコマンドを書くと、発言を保存するときにアプリがそれを実行します。
この文書は、コマンドごとの書式・前提条件・有効にする設定・記録の残り方をまとめます。
決めた理由と測定は [設計書](multi-agent-chat-design.md) の §4.8 (ダイスと判定、会話ごとの有効なコマンド、効果コマンド) にあります。

| コマンド | すること |
| --- | --- |
| [`/roll`](#roll) | アプリがダイスを振り、目標値と比べて成否を付ける |
| [`/add`](#add) | 状態の項目の値の先頭の整数に加減する |
| [`/use`](#use) | 状態の項目の値の先頭の整数から 1 を引く (1 未満なら使えない) |
| [`/set`](#set) | 状態の項目の値を置き換える (行が無ければ足す) |

`/add`・`/use`・`/set` をまとめて**効果コマンド**と呼びます。効果コマンドが書き換えるのは状態シート
(共通の状態と参加者の状態、「項目名: 値」の行) です。

## 共通の決まり

- **有効にしたコマンドだけが動きます。** 会話ごとの設定 (chat の `commands`) にコマンド名のキーがあれば有効です。
  インスペクタの状態の区画のチェックボックスか、プリセットの `commands` で有効にします。
  プリセットを使わずに作った会話では、どのコマンドも有効になっていません。
  有効にしていないコマンドの行は、書かれたとおりの本文として残ります。
- **実行するのは 1 つの発言につき 1 つだけで、置き場所は最後の行です。** 本文の最後の文に続けて書いたもの (`…渡る。/roll 1d20+3 岩棚を渡る`) も受けます。
  最後の行に有効なコマンドが 2 つあれば、先に書いたほうだけを読み、残りはその引数として扱います。
  効果コマンドだけは、最後の行にコマンドが無いとき、途中の行も読みます。上から見て最初の、書式が読める効果コマンドを 1 つだけ実行し、
  その位置から行末までを本文から除きます (傷を描写した文に続けて `/add` を書き、改行して描写を続けるモデルがいるため)。
  途中の行の読めない効果コマンドは、コマンドの説明の文でもありうるので、本文として残します (人間の介入発言でも入力欄に返しません)。
  コマンドの語は単独の語であることが要り、`/address` や URL の一部 (`example.com/roll`) はコマンドになりません。
- **参加者の発言でも人間の介入発言でも同じに動きます。** 書式が読めないコマンドは、参加者の発言では本文に残し
  (ターンは失敗にしません)、人間の介入発言では入力欄に残したまま理由を返します (400)。
- **コマンドの行は保存する本文から除き、記録として発言に残します。** 記録は発言の下にチップで出て、
  以後の話者には本文の後の 1 行として渡り、markdown エクスポート・コピー・メモリ保存の下書きにも入ります。
  コマンドだけの発言も保存します。記録は別の発言にはしないので、どのターン進行ルールも話者の選び方が変わりません。
- `[次: 表示名]` の指示子もあるときは、指示子 → コマンド → 名前の照合 の順に処理します。
  コマンドの行に含まれる名前は呼びかけになりません。
- 全角の数字・符号 (`＋`・`−`)・空白も受けます。
- コマンドを無効にしても、記録済みの判定・効果はチップにも以後の話者の prompt にも残ります。

## `/roll`

```
/roll <式> [目標<整数>] [行動]
/roll 1d20+3 目標12 岩棚を渡る
```

- 式は `NdM`・`NdM+K`・`NdM-K` (N は 1〜20、M は 2〜100、K は 999 まで)。
- 目標は `目標12`・`目標 12`・`目標:12` のどれでもよく、英語で遊ぶ卓のために `target12` も受けます。
  `目標なし`・`目標0` は比べずに合計だけを記録します。`目標` で始まる欄が 1〜9999 の整数でなければ、書式が読めないコマンドです。
- 目標値はコマンドの `目標N`、無ければ既定の目標値 (設定の `target`) の順で決め、合計がそれ以上なら成功です。どちらも無ければ合計だけを記録します。
- 乱数はアプリが出します。ダイス専用のボタンは無く、入力欄で `/` を打つと書式の候補が出ます。
- `/roll` を有効にした会話では、行頭が【ダイス】で始まる行もアプリの記法として扱います。
  結果の無い `【ダイス】1d20+3 行動` が最後の行にあれば `/roll` として振り、結果の形をした【ダイス】行はアプリが振っていないので本文から除きます。

設定:

```json
"commands": { "roll": { "target": 12 } }
```

`target` は目標を書かない `/roll` の合計と比べる既定の目標値で、0〜9999 の整数 (0 は比べない)。
比べない卓では `"roll": {}` と書きます。インスペクタの状態の区画で会話中も変えられます。
プリセットのトップレベルの `diceTarget` (古い形式) は `commands.roll.target` として読みます (`commands` と一緒には書けません)。

記録: 各ダイスの目・修正値・合計・目標値・成否。チップは「🎲 岩棚を渡る 1d20+3 → 4+3 = 7 / 目標 12 失敗」、
以後の話者には「【ダイス】岩棚を渡る — 1d20+3 → 4+3 = 7（目標 12、失敗）」として渡ります。

## 効果コマンドの持ち主と項目

効果コマンドは `/<コマンド> <持ち主> <項目名> …` の形です。

- **持ち主**は「共通」(共通の状態) か、参加者の名前です。名前は表示名そのものか、括弧書きを除いた部分 (`レン (斥候)` なら `レン`) で、
  大文字小文字は区別しません。2 人以上が持つ名前 (`買い手 (部長)` と `買い手 (情シス)` の `買い手`) では指せないので、表示名全体を書きます。
  編成にいない名前は書式が読めないコマンドとして扱います。
- **項目名**は、状態シートの行の最初の `:` (`：`) より前の部分です (前後の空白は除き、大文字小文字は区別しません)。
  項目名に `:` を付けて書いてもかまいません (`/set 共通 場所: 第二坑道`)。同じ項目名の行が 2 つあれば、上の行に当てます。
- **前提条件と上限は、効果を当てる時点の状態シートで判定します。** 満たさない効果は当てず、その旨を記録に残します
  (チップは赤い調子になり、以後の話者には「適用されず（…）」として渡ります)。ターンの生成中に人間が状態シートを直していれば、直した値で判定します。
- 上限は共通の状態が 400 字、参加者の状態が 1 人 200 字です。当てると上限を超える効果は当てません。

当てなかった理由:

| 理由 | 表示 | 起きるコマンド |
| --- | --- | --- |
| `missing_item` | 「たいまつの行が無い」 | `/add`・`/use` |
| `not_integer` | 「所持品の値が整数で始まらない」 | `/add`・`/use` |
| `not_positive` | 「たいまつが 1 未満」 | `/use` |
| `over_limit` | 「状態が 200 字を超える」 | すべて |

設定は 3 つとも持たず、キーがあれば有効です。コマンドごとに有効にできます。

```json
"commands": { "add": {}, "use": {}, "set": {} }
```

## `/add`

```
/add <持ち主> <項目名> <±整数 または 式>
/add レン HP -3
/add ミラ HP -1d6+1
```

- 値の先頭の整数に加減し、残りの文字はそのままにします (`HP: 7/10` に `-3` で `HP: 4/10`、`たいまつ: 2 本` に `-1` で `たいまつ: 1 本`)。
- 量は `±整数` (符号が無ければ足す、9999 まで) か、`/roll` と同じ範囲の式です。式はアプリが振り、先頭の符号は式全体に掛かります (`-1d6+1` は 1d6+1 を引く)。
  量の後に何か書くと、書式が読めないコマンドです。
- 前提条件: 行があり、値の先頭が整数であること。結果が 0 未満になっても当てます。
- 記録の表示: 「レン HP -3: 7/10 → 4/10」「ミラ HP -1d6+1（3+1 = 4）: 14/14 → 10/14」。式の出目は前提条件を満たしたときだけ振ります。

## `/use`

```
/use <持ち主> <項目名>
/use レン たいまつ
```

- 値の先頭の整数から 1 を引きます (`/add <持ち主> <項目名> -1` と同じ計算)。
- 前提条件: 行があり、値の先頭の整数が 1 以上であること。持っていない物は使えません。
- 記録の表示: 「レン たいまつ -1: 2 → 1」、使えなかったときは「レン たいまつ -1 — 適用されず（たいまつが 1 未満）」。

## `/set`

```
/set <持ち主> <項目名> <値>
/set 共通 場所 第二坑道の分かれ道
```

- 項目の値を、項目名の後の残り全部 (空白を含んでよい) で置き換えます。行が無ければ末尾に「項目名: 値」を足します。値が空なら書式が読めないコマンドです。
- 前提条件は無く、上限だけを判定します。
- 記録の表示: 「共通 場所: 灰縁坑の入口 → 第二坑道の分かれ道」、行が無かったときは「共通 場所: （無し） → 第二坑道の分かれ道」。

## プリセットに書くとき

いつコマンドを書くかはゲームごとの規則なので、アプリの側では決めません。`scenePrompt` か役割プロンプトに書いてください。
効果コマンドは消耗品を項目ごとの行 (`たいまつ: 2`) にしておくと `/use` が当たります。「所持品: たいまつ 2 本、ロープ」の 1 行では、`たいまつ` の行がありません。

同梱の `trpg-table` は、結果が不確かな行動に `/roll 1d20+修正 行動` を書く規則、傷は GM が `/add`、たいまつ・包帯はプレイヤーが `/use`、
移動は GM が `/set 共通 場所 …` で記録する規則と、`"commands": { "roll": { "target": 12 }, "add": {}, "use": {}, "set": {} }` を持ちます。
形式全体は [プリセットの形式](multi-agent-presets.md) を見てください。
